# 调试工具—无线急停盒 USB Serial 通信协议

**文档版本：** V1.0  
**通信双方：** 调试工具 ↔ 无线急停盒  
**通信接口：** USB Serial  

## 1. 概述

本文规定调试工具与无线急停盒之间的 USB Serial 通信协议。

协议支持以下功能：

- 无线通信参数读取；
- 无线通信参数配置；
- SDO 对象读取；
- SDO 对象写入；
- PIN 配置。

对应系统指令如下：

| 请求 | 响应 | 功能 |
|---:|---:|---|
| `0x04` | `0x84` | 读取通信参数 / 读取 SDO |
| `0x05` | `0x85` | 配置通信参数 / 写入 SDO |
| `0x07` | `0x87` | 配置 PIN |

### 1.1 串口参数

| 参数 | 值 |
|---|---|
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |

### 1.2 通用帧规则

所有业务帧固定为 **42 Byte**。

- 多字节整数采用小端；
- 字节数组按原序发送；
- 保留字段发送时置 0；
- Byte39 为结果码；
- Byte40～41 为 CRC；
- CRC 使用 CRC16-XMODEM；
- CRC 计算范围为 Byte0～39；
- CRC 低字节在前。

当前协议通用结果码：

| 数值 | 含义 |
|---:|---|
| `0x00` | 处理成功 |
| `0xFF` | 处理失败 |

其他结果码尚未定义。

## 2. 通信参数读写

### 2.1 基本格式

读取通信参数使用 `0x04`，配置通信参数使用 `0x05`。

响应分别使用：

```text
0x84：读取响应
0x85：配置响应
```

两类响应均回显请求中的事务 ID。

Object Index：

```text
Object Index == 0
    读写完整通信参数

Object Index != 0
    操作 SDO
```

公共字段如下：

| Byte | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | 系统指令 | uint8 | `0x04` / `0x05` |
| 1～4 | 事务 ID | uint32 | 非 0 |
| 5～6 | Object Index | uint16 | 完整参数操作时为 0 |
| 7～10 | Object Data | uint32 | 完整参数操作时为 0 |
| 11～12 | 参数标志 | uint16 | 见 2.2 |
| 13～38 | 参数数据 | - | LoRa / GFSK |
| 39 | 结果码 | uint8 | 请求固定 0 |
| 40～41 | CRC | uint16 | CRC16-XMODEM |

事务 ID 规则：

- 每次独立读取或配置使用新的非 0 事务 ID；
- 同一请求重试时事务 ID 保持不变；
- 响应回显请求事务 ID。

### 2.2 参数标志

参数标志为 `uint16`：

| 位 | 名称 | 编码 | 约束 |
|---|---|---|---|
| bit15..14 | 操作类型 | `00` LoRa；`01` GFSK；`10/11` 保留 | `10/11` 返回参数错误 |
| bit13..6 | 保留 | 固定 0 | 非 0 返回参数错误 |
| bit5 | 信道扫描方式 | `0` 单信道；`1` 跳信道 | 跳信道时公共信道暂定 CH1 433.25 MHz |
| bit4 | 分组模式 | `0` 一对一；`1` 一对多 | |
| bit3 | 心跳包开关 | `0` 开启；`1` 关闭 | |
| bit2 | 无线急停开关 | `0` 开启；`1` 关闭 | 关闭属于受控维护操作 |
| bit1 | 物理层 CRC 开关 | `0` 开启；`1` 关闭 | LoRa 使用芯片 LoRa CRC；GFSK 使用 CRC-16/CCITT-FALSE |
| bit0 | 频段 | `0` 433 MHz；`1` 915 MHz | 必须匹配硬件识别结果 |

### 2.3 LoRa 参数

LoRa 参数帧：

| Byte | 字段 | 类型 | 协议值 / 范围 | 单位 |
|---|---|---|---|---|
| 13～14 | 发射功率 | int16 | 0～22；433 MHz ≤10；915 MHz ≤20 | dBm |
| 15～16 | 信道中心频率偏移 | uint16 | 中心频率 = 基值 + 偏移 | kHz |
| 17 | 负载字节长度 | uint8 | 固定 12 | Byte |
| 18 | 信号接收强度门槛 | uint8 | raw=10～148，实际值=-raw | dBm |
| 19～20 | 心跳包间隔 | uint16 | 200～10000 | ms |
| 21 | 心跳丢失判断门槛 | uint8 | 1～255 | 包 |
| 22 | 接收带宽 | uint8 | `0`=125；`1`=250；`2`=500 | kHz |
| 23 | 扩频因子 | uint8 | 5～12 | - |
| 24 | 编码率 | uint8 | 见下表 | - |
| 25 | 报头类型 | uint8 | `0` 显式；`1` 隐式 | - |
| 26 | 前导码长度 | uint8 | 10～50；默认 12；SF5/SF6 固定 12 | symbol |
| 27～28 | 同步字 | uint16 | `0xY4X4` | - |
| 29～38 | 保留 | uint8[10] | 固定 0 | - |

频率基值：

```text
433 MHz：433000 kHz
915 MHz：902000 kHz
```

编码率：

| 协议值 | 编码率 |
|---:|---|
| 0 | 4/5 |
| 1 | 4/6 |
| 2 | 4/7 |
| 3 | 4/8 |
| 4 | LI4/5 |
| 5 | LI4/6 |
| 6 | LI4/8 |

隐式报头模式要求收发负载长度一致。

同步字格式为 `0xY4X4`，每字节低 4 位固定为 4：

```text
默认私网：0x1424
公网：    0x3444
```

读取请求中参数数据字段置 0；配置请求中填写目标参数。

### 2.4 GFSK 参数

GFSK 参数帧：

| Byte | 字段 | 类型 | 协议值 / 范围 | 单位 |
|---|---|---|---|---|
| 13～14 | 发射功率 | int16 | 0～22；433 MHz ≤10；915 MHz ≤20 | dBm |
| 15～16 | 信道中心频率偏移 | uint16 | 中心频率 = 基值 + 偏移 | kHz |
| 17 | 负载字节长度 | uint8 | 固定 12 | Byte |
| 18 | 信号接收强度门槛 | uint8 | raw=10～148，实际值=-raw | dBm |
| 19～20 | 心跳包间隔 | uint16 | 200～10000 | ms |
| 21 | 心跳丢失判断门槛 | uint8 | 1～255 | 包 |
| 22 | 接收带宽 | uint8 | `0`=117.3；`1`=234.3；`2`=467 | kHz |
| 23～26 | 码率 | uint32 | 600～150000 | bps |
| 27～30 | 频偏 | uint32 | 600～300000 | Hz |
| 31 | 脉冲整形 | uint8 | 见下表 | - |
| 32 | 前导码长度 | uint8 | 16～255；默认 16 | bit |
| 33～34 | 同步字 | uint16 | 16 bit | - |
| 35～38 | 保留 | uint8[4] | 固定 0 | - |

频偏与码率必须满足：

```text
2 × 频偏 / 码率 >= 0.5
```

脉冲整形：

| 协议值 | 含义 |
|---:|---|
| `0x00` | 无滤波 |
| `0x08` | BT 0.3 |
| `0x09` | BT 0.5 |
| `0x0A` | BT 0.7 |
| `0x0B` | BT 1.0 |

GFSK 前导码检测长度固定为 8 bit。

读取请求中参数数据字段置 0；配置请求中填写目标参数。

### 2.5 通信参数响应

读取响应：

```text
Command = 0x84
```

配置响应：

```text
Command = 0x85
```

响应公共字段：

| Byte | 字段 | 说明 |
|---|---|---|
| 0 | 系统指令 | `0x84` / `0x85` |
| 1～4 | 事务 ID | 回显请求事务 ID |
| 5～6 | Object Index | 参数操作时为 0 |
| 7～10 | Object Data | 参数操作时为 0 |
| 11～38 | 参数数据 | 按 LoRa / GFSK 对应格式 |
| 39 | 结果码 | 处理结果 |
| 40～41 | CRC | CRC16-XMODEM |

参数读取成功时返回当前参数。

## 3. SDO 协议

通信参数命令同时用于 SDO 访问：

```text
0x04 / 0x84：读取
0x05 / 0x85：写入
```

### 3.1 Object Index

Object Index 为 16 bit：

```text
高 4 bit：操作或响应状态
低 12 bit：对象地址
```

请求：

| 高 4 bit | 操作 | Object Data |
|---:|---|---|
| `0x0` | 读 | 固定 0 |
| `0x1` | 写 | 写入值 |

响应：

| 高 4 bit | 状态 | Object Data |
|---:|---|---|
| `0x4` | 读命令执行成功 | 读取值 |
| `0x6` | 写命令执行成功 | 固定 0 |
| `0x0` | 从机未收到 | 固定 0 |
| `0xB` | 命令执行中 | 固定 0 |
| `0x8` | 发生错误 | 固定 0 |
| `0xE` | 无效命令 | 固定 0 |

### 3.2 无线急停盒对象字典

| Object Index | 对象 | 类型 / 权限 | Object Data / 约束 |
|---:|---|---|---|
| `0x001` | Product Code | uint32 / RO | 设备产品编码 |
| `0x002` | Version Number | uint32 / RO | 设备版本号 |
| `0x003` | Serial Number | uint32 / RO | 设备序列号 |
| `0x004～0x007` | RESERVED | uint32 / RO | 固定 0 |
| `0x008～0x011` | App_Firmware_Version | string[40] / RO | 每索引返回 4 个 ASCII 字符 |
| `0x012～0x01B` | Bootloader_Firmware_Version | string[40] / RO | 每索引返回 4 个 ASCII 字符 |
| `0x01C～0x025` | AppBranchName | string[40] / RO | 每索引返回 4 个 ASCII 字符 |
| `0x026～0x02F` | AppTagSha1Id | string[40] / RO | 每索引返回 4 个 ASCII 字符 |
| `0x030～0x039` | BootBranchName | string[40] / RO | 每索引返回 4 个 ASCII 字符 |
| `0x03A～0x043` | BootTagSha1Id | string[40] / RO | 每索引返回 4 个 ASCII 字符 |
| `0x044～0x0FF` | RESERVED | uint32 / RO | 固定 0，读取返回 0 |
| `0x102` | 电量 | uint32 / RO | 0～100，单位 1% |
| `0x202` | Upgrade_Request_flag | uint32 / RW | `0x454E`：升级标志 |

`string[40]` 对象使用连续 10 个索引，每个索引返回 4 个 ASCII 字符；不足 40 字符时以 `0x00` 结束并补 0。

## 4. PIN 配置协议

### 4.1 PIN 配置请求

方向：

```text
调试工具 → 无线急停盒
```

Command：

```text
0x07
```

帧格式：

| Byte | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | 系统指令 | uint8 | `0x07` |
| 1～6 | PIN | uint8[6] | 6 Byte ASCII 数字 |
| 7～11 | 保留 | uint8[5] | 固定 0 |
| 12～15 | 事务 ID | uint32 | 新的非 0 事务 ID |
| 16～38 | 保留 | uint8[23] | 固定 0 |
| 39 | 结果码 | uint8 | 固定 0 |
| 40～41 | CRC | uint16 | CRC16-XMODEM |

PIN 每个字节范围：

```text
0x30 ～ 0x39
```

同一请求重试时保持事务 ID 不变。

### 4.2 PIN 配置响应

方向：

```text
无线急停盒 → 调试工具
```

Command：

```text
0x87
```

帧格式：

| Byte | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | 系统指令 | uint8 | `0x87` |
| 1～6 | PIN | uint8[6] | 回显 PIN |
| 7～11 | 保留 | uint8[5] | 固定 0 |
| 12～15 | 事务 ID | uint32 | 回显请求事务 ID |
| 16～38 | 保留 | uint8[23] | 固定 0 |
| 39 | 结果码 | uint8 | 处理结果 |
| 40～41 | CRC | uint16 | CRC16-XMODEM |

## 6. 协议能力与调试工具需求匹配分析

根据《急停配置工具迭代1需求 V1.7.0》，无线急停盒配置功能要求调试工具至少支持：

1. 显示当前连接急停盒的 Device ID；
2. 读取 PIN 码；
3. 配置出厂 PIN 码；
4. 读取无线通信参数；
5. 配置无线通信参数；
6. 恢复默认通信参数。

其中无线通信参数包括：

- 参数标志；
- 发射功率；
- 信道中心频率偏移；
- 负载字节长度；
- 信号接收强度门槛；
- 心跳包间隔；
- 心跳丢失判断门槛；
- 接收带宽；
- 扩频因子；
- 编码率；
- 报头类型；
- 前导码长度；
- 同步字；
- 操作类型；
- 信道扫描方式；
- 分组模式；
- 心跳包开关；
- 无线急停开关；
- 物理层 CRC 开关；
- 频段。

### 6.1 能力匹配

| 调试工具需求 | 当前协议能力 | 结论 |
|---|---|---|
| 读取通信参数 | `0x04 / 0x84`，Object Index=0 | 满足 |
| 配置通信参数 | `0x05 / 0x85`，Object Index=0 | 满足 |
| LoRa 参数配置 | 已定义完整字段、范围和编码 | 满足 |
| GFSK 参数配置 | 已定义完整字段、范围和编码 | 满足 |
| SDO 信息读取 | `0x04 / 0x84`，Object Index!=0 | 满足 |
| SDO 信息写入 | `0x05 / 0x85`，Object Index!=0 | 满足 |
| 配置 PIN | `0x07 / 0x87` | 满足 |
| 读取 PIN | 无对应读取指令 | **不满足** |
| 显示急停盒 Device ID | 无独立 Device ID 查询指令或 SDO 对象 | **不满足** |
| 恢复默认通信参数 | 定义了默认参数表，但无恢复默认指令 | **部分满足** |

### 6.2 通信参数覆盖情况

需求中列出的通信参数与当前协议字段能够对应。

公共参数：

| 需求参数 | 协议字段 |
|---|---|
| 参数标志 | Byte11～12 Parameter Flags |
| 发射功率 | Byte13～14 |
| 信道中心频率偏移 | Byte15～16 |
| 负载字节长度 | Byte17 |
| 信号接收强度门槛 | Byte18 |
| 心跳包间隔 | Byte19～20 |
| 心跳丢失判断门槛 | Byte21 |
| 操作类型 | Parameter Flags bit15..14 |
| 信道扫描方式 | Parameter Flags bit5 |
| 分组模式 | Parameter Flags bit4 |
| 心跳包开关 | Parameter Flags bit3 |
| 无线急停开关 | Parameter Flags bit2 |
| 物理层 CRC 开关 | Parameter Flags bit1 |
| 频段 | Parameter Flags bit0 |

LoRa 参数：

| 需求参数 | 协议字段 |
|---|---|
| 接收带宽 | Byte22 |

### 6.3 当前协议缺口

#### Device ID 查询

产品需求要求显示“当前连接的急停盒 Device ID”。

当前调试工具—无线急停盒协议没有定义：

```text
读取 Device ID 指令
```

无线急停盒 SDO 对象字典虽然包含：

```text
Product Code
Version Number
Serial Number
```

但原协议没有说明其中任何对象等同于无线急停盒 Device ID，因此不能使用 `Serial Number` 或其他 SDO 字段替代 Device ID。

结论：

```text
Device ID 查询能力缺失。
```

#### PIN 读取

产品需求要求：

```text
读取 PIN
配置出厂 PIN
```

当前协议只定义：

```text
0x07 / 0x87：PIN 配置
```

没有定义 PIN 查询或读取指令。

结论：

```text
PIN 配置能力满足；
PIN 读取能力缺失。
```

#### 恢复默认参数

产品需求要求：

```text
恢复默认通信参数
```

当前协议定义了 LoRa 和 GFSK 的出厂默认参数，但没有定义独立的：

```text
Restore Defaults
```

系统指令。

从现有协议能力看，可以通过 `0x05` 将文档中规定的默认参数重新写入无线急停盒，从而得到与默认参数一致的通信配置；但原协议没有说明该操作等价于设备固件级“恢复默认”。

因此：

```text
默认参数值已定义；
恢复默认协议动作未定义。
```

如产品要求“恢复默认”仅表示恢复通信配置，可以明确规定其语义为“使用 0x05 写入协议默认参数”。

如产品要求设备执行固件级恢复默认，则需要新增正式协议定义。

### 6.4 结论

当前调试工具—无线急停盒通信协议可以完整支持：

```text
通信参数读取
通信参数配置
LoRa / GFSK 参数配置
SDO 读写
PIN 配置
```

但尚不能完整满足《急停配置工具迭代1需求 V1.7.0》。

当前缺口为：

```text
1. Device ID 独立查询；
2. PIN 读取；
3. 恢复默认操作语义 / 指令。
```

因此当前协议的总体结论为：

> **部分满足调试工具无线急停盒配置需求。**

在进入正式联调前，需要对以上三个协议缺口完成确认；其中“恢复默认”可以选择复用现有 `0x05` 写入默认参数，而 Device ID 查询和 PIN 读取需要原协议补充明确的访问方式。
